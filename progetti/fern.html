Assistente AI per le API

Fern

Un chatbot che usa qualsiasi API al posto tuo: carichi la specifica OpenAPI e chiedi quello che ti serve in linguaggio naturale.

Open source

Codice su GitHubIl post su LinkedIn

Di cosa si tratta

Le API sono potenti, ma per usarle bisogna leggere la documentazione, capire parametri e autenticazione e scrivere la richiesta. Fern fa questo lavoro al posto tuo: legge il file OpenAPI, capisce cosa chiedi, sceglie l'endpoint, compila i parametri, esegue la chiamata e ti risponde in modo leggibile.

Il modello, Mistral, gira in locale con Ollama: le tue richieste e le tue chiavi non escono dal computer.

Progetto personale e open source, con licenza MIT.

Cosa fa

  • Caricamento di raccolte di API da file OpenAPI (.json), salvate in SQLite.
  • Elenco delle API disponibili e lettura automatica dei parametri.
  • Mappatura dei parametri nel path o nella query.
  • Autenticazione con API key.
  • Risposte riformulate in linguaggio naturale.

Scelte tecniche

  • Modello in localeCon Ollama nessun dato passa da servizi esterni: è importante quando le API sono aziendali.
  • Dal linguaggio naturale al JSONIl modello produce una richiesta strutturata, che viene validata sulla specifica OpenAPI prima della chiamata.
