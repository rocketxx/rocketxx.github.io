Tav. VI

Lettore Markdown

mdreader

Un lettore ed editor di file Markdown in una sola pagina HTML: niente da installare, funziona offline e i documenti restano sul tuo computer.

Open source

Apri mdreaderCodice su GitHub

Di cosa si tratta

Volevo leggere e modificare file Markdown senza installare niente e senza caricarli su un servizio online. mdreader è un unico file HTML: lo apri, trascini il documento e lo leggi con indice, ricerca, diagrammi e formule.

Progetto personale e open source.

Cosa fa

  • Lettura: indice laterale che segue la sezione, barra di avanzamento, ricerca nel documento, temi chiaro e scuro.
  • Codice evidenziato con pulsante di copia, diagrammi Mermaid, formule KaTeX, box di avviso in stile GitHub.
  • Editor con barra di formattazione, liste che continuano da sole, checkbox cliccabili e scorrimento sincronizzato.
  • Esportazione in .md, HTML autonomo, testo formattato per Word e Outlook, PDF.
  • Archivio nel browser con ricerca, selezione multipla ed export zip.

Scelte tecniche

  • Un solo fileUno script di build mette tutto in un index.html: si può scaricare, mandare per email o aprire da una chiavetta.
  • Sicuro per defaultL'HTML prodotto dal Markdown passa da DOMPurify prima di essere mostrato.
  • PrivatoNessun server: i documenti restano nel browser e solo se scegli di salvarli.
