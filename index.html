Progetti

Vocablio

vocablio.org

Un’app per imparare l’inglese leggendo libri veri, una pagina alla volta. Tocchi una parola o una frase e ne vedi subito la traduzione, nel suo contesto.

Prova come funziona: tocca una parola sottolineata.

It is a , that a man in of a good , must be in of a .

Jane Austen, Pride and Prejudice, 1813

La traduzione compare qui.

È una verità universalmente riconosciuta che uno scapolo in possesso di un buon patrimonio debba essere in cerca di una moglie.

La parte di cui vado più fiero

Il sistema di ricerca nei video, costruito da zero. Data una parola inglese, trova un video in cui qualcuno la pronuncia e ti porta esattamente a quella frase. Così impari pronuncia, intonazione e slang da un contesto reale, non da un dizionario.

Tecnologie: Capacitor, Cloudflare Workers, scraping, Google Translate API

Open source e progetti personali

  • Fern, assistente per le API

    Un chatbot per usare qualsiasi API scrivendo in linguaggio naturale. Carichi un file OpenAPI e Fern, con Mistral eseguito in locale tramite Ollama, interpreta la richiesta, compila i parametri e chiama l’endpoint giusto.

    Tecnologie: Python, Streamlit, Ollama, Mistral, OpenAPI, SQLite

    GitHub

  • Order Queue System

    Gestione ordini asincrona con Spring Boot e RabbitMQ: per ogni ordine genera un PDF con iText 7 e lo invia per email come allegato.

    Tecnologie: Java 17, Spring Boot, RabbitMQ, iText 7, SMTP

    GitHub

  • SentimenTitle

    Analisi del sentiment in tempo reale sui titoli di BBC News, The Verge e TechCrunch, raccolti tramite NewsAPI. Un piccolo modello, Word2Vec con regressione logistica in Spark MLlib, addestrato sul dataset pubblico Sentiment140, classifica ogni titolo come positivo, neutro o negativo. I dati passano da Logstash e Kafka a Spark Streaming e finiscono in una dashboard Kibana. Progetto di tesi.

    Tecnologie: Kafka, Spark MLlib, Logstash, Elasticsearch, Kibana, Docker Compose

    GitHub

    Tecnologie: JavaScript, Docker, Kibana
